# Dark Kingdom appearance

Dark Kingdom replaces the previous green dark palette. New browsers default to it; previously saved light/dark choices remain respected. Settings offers Classic Light and Dark Kingdom. The theme is entirely client-side and does not modify player data, travel, or map rendering.

- Shared charcoal/brass variables, compact nav and resource meters, restrained carved panel borders.
- A local, original SVG castle panorama on Home; no remote assets or runtime animation.
- Responsive three-column Home at desktop widths, two or one columns below.
- Existing category colors, copy buttons, accessible focus and Renown functionality retained.

The castle artwork is a stylized first-pass illustration; it can later be replaced with a more detailed locally hosted illustration without changing the UI. The classic light theme remains selectable.
